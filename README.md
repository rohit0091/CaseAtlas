## 🌍 CaseAtlas

### Community-Driven Case Tracking Platform

A full-stack platform designed to help users **track ongoing cases, follow updates, and interact with community-driven information**.

### 🔧 Built With

`Node.js` `Express.js` `MongoDB` `JWT` `Vue.js` `JavaScript`

### ✨ Features

- 🔑 User registration and authentication
- 🛡️ JWT authentication
- 🚪 Protected routes
- 👤 User profiles
- ➕ Follow / unfollow functionality
- 👍 Upvote / downvote system
- 🔄 Live counter updates
- 🗄️ MongoDB-based backend
- ⚡ RESTful API architecture

- Backend API architecture
- Authentication & authorization
- Database modelling
- JWT implementation
- Frontend/backend integration
- REST API development
- Full-stack application structure
